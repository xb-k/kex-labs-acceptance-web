# Mirza-Luqman/prompt-storyboard-studio（戏剧连续性 · 小说多章 · 视觉散文规范）

- **上游仓库**：`Mirza-Luqman/prompt-storyboard-studio` (`https://raw.githubusercontent.com/Mirza-Luqman/prompt-storyboard-studio/main/README.md`)
- **适用剧本模板**：`narrative`（剧情叙事）、`historical_novel`（小说历史长故事）、`scenic_essay`（视觉散文）

## 核心规则
1. **轴线与连续性锁定**：每一镜必须显式记录 `continuity_anchor`（人物站位朝向、道具持握状态、主光方向）。
2. **整部小说多章脉络**：先确立跨章节时代锚点与人物弧光总纲（chapters），再细化当前开篇集的分场镜号。
3. **光学写实**：杜绝 4K/8K/hyperrealistic 等空洞黑话，全部转为精确焦段与物理光源描写。
