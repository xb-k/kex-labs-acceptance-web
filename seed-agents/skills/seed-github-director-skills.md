# 0xhughs/director-skills（观察式纪录片 & 生活方式 Vlog 规范）

- **上游仓库**：`0xhughs/director-skills` (`https://raw.githubusercontent.com/0xhughs/director-skills/main/README.md`)
- **适用剧本模板**：`documentary`（人文纪实 · 观察式纪录片）、`vlog`（生活方式 · 轻纪实 Vlog）

## 核心规则
1. 观察式纪录片禁止商业口号与过度推拉柔焦，强制 35mm/50mm 人文定焦与 4.0s~6.5s 长镜头呼吸节奏。
2. 光源按现场物理色温锁定（4500K-5600K），同期环境底噪与器物拟音优先（Diegetic Sound First）。
3. Vlog 模式强调第一人称贴身跟拍、动作匹配转场（Match Cut）与生活化口语旁白。
