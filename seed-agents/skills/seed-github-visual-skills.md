# smixs/visual-skills & juspay/director（商业营销 & 产品微距规范）

- **上游仓库**：`smixs/visual-skills` (`https://raw.githubusercontent.com/smixs/visual-skills/main/README.md`)
- **适用剧本模板**：`marketing`（营销广告 · 高转化商业片）、`product_demo`（产品演示 · 极简工业微距）

## 核心规则
1. 前 2.5s~3.5s 必须建立强视觉钩子（Visual Hook）与材质反差，避免无效空镜。
2. 商业片采用 85mm 材质微距与 35mm/50mm 场景中景交替，突出 specular highlights 与 tactile micro-detail。
3. 产品演示严禁手持晃动，全部运动使用电控滑轨 / 机械臂弧线围绕与棚拍可控轮廓扫光。
