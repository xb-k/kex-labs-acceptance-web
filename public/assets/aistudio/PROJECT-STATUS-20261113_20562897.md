## 1. 目标与双轨定义（用户口径）

| 轨 | 定义 | 输入 | AI 的角色 | 核心风险 |
|---|---|---|---|---|
| **A · AIGC 生成** | 脚本/分镜从零生成 | 脚本 + 参考图/关键帧（可无实拍） | 主生产者（T2V / I2V） | AI 感、主体熔坏、镜头间不一致 |
| **B · 实拍优化剪辑** | 实拍为主，AI 只增强与剪辑 | ≥30s / 5~8 镜实拍 | 增强者（调色/超分/插帧/降噪/片段级重绘/剪辑） | 「优化」变「毁片」：熔脸、色漂、过锐、鬼影 |

**写死的规则**：
- A 轨主生成器顺序：**LTX-2.3 22B（q8）→ Wan2.1-I2V-14B fp8（备选）→ Wan2.2-TI2V-5B（末选）**。
- B 轨**禁止整片 i2v 重绘**（实证 LTXV 2B strength 0.65 融化、0.35 人物消失）；主链 = Director 调色 + Real-ESRGAN 超分 + RIFE 插帧 + assemble 剪辑；LTX-2.3 仅允许片段级补拍/换景，必须带结构锚定、可回退原片。

### 1.1 交付硬指标

| 项 | A 轨 | B 轨 |
|---|---|---|
| 时长 | 60s（12 镜）/ 30s（6 镜）；样片 5s / 15s | 同左 |
| 分辨率 | 平台定；默认 1620×1080 或 1280×704 | **保持源比例**（竖屏就竖屏） |
| 帧率 | 30fps（或 24，全链一致） | 源帧率或插帧 60fps |
| 编码 | H.264 yuv420p / AAC | 同左 |
| 音频 | edge-tts 中文旁白 + BGM；音画 offset ≤1 帧 | 保留原声或替换旁白，offset ≤1 帧 |
| 命名 | `sample-60s.mp4` / `sample-30s.mp4` | 同左 |

## 6. 六阶段流水线（A→F，phase-major）

> 阶段串行：一个阶段处理完全部镜头再进下一阶段；阶段间卸载上一模型并确认内存。

| 阶段 | 工具（`tools/`） | 模型 | 输入 → 输出 | 典型失败 |
|---|---|---|---|---|
| **A** | `probe_video` / `split_shots` / `extract_frames` | 无重型模型 | 源视频 → 镜头切分 + 关键帧 | 测试图/彩条混入（有输入门禁） |
| **B** | `describe_frames` | Qwen2-VL（Ollama，`keep_alive=0`） | 关键帧 → 语义描述 | Ollama 未起/内存未卸 |
| **B2** | `select_profile` | 纯函数 | 语义 → profile/look/bgm_tone | 非确定性 |
| **C** | `render_frames` | SDXL img2img（ComfyUI） | 关键帧 → 风格化关键帧 | 结构丢失、denoise 过高熔脸 |
| **D** | `generate_clips` | LTXV I2V（LTX-2.3 待接） | 关键帧 → 3~5s 片段（3×49f 链式） | 尾段崩、拖影、形体崩坏 |
| **E** | `interpolate` → `upscale` → `grade_color` | RIFE / Real-ESRGAN / 调色 | 片段 → 60fps + 高分 + 统一色彩 | 鬼影、振铃、偏色 |
| **F** | `synthesize_audio` / `assemble` / `archive` | edge-tts + ffmpeg | 片段 + 音频 → 成片 + 报告 | offset、切点跳帧、缺 ffprobe |

### 6.1 A/B 轨差异

| 阶段 | A 轨 | B 轨 |
|---|---|---|
| A | 跳过实拍切分：脚本 → 分镜表 | 正常切分 + 关键帧 |
| B | 参考图/关键帧描述 | 正常 |
| C | 关键帧生成主力（SDXL） | 少量重绘（需保结构） |
| D | 主生成（LTX-2.3/Wan） | **默认不生成**：`KEX_D_REUSE_SOURCE=1` 复用源片 |
| E | 超分/插帧/调色 | **主力**：超分 + 插帧 + 降噪 + 统一调色 |
| F | 旁白 + BGM + 封装 | 剪辑（切点/节奏/转场）+ 原声处理 + 封装 |

### 6.2 阶段硬契约

1. `ToolResult = {status: ok|failed|blocked|needs_human, output, error, cost}`；非 ok 必带 error。
2. 幂等键 `(tool, args_hash, input_hash)`；命中直接返回。
3. `state.json` 原子写（tmp + `os.replace`），字段至少 `job_id/stage/shots/frames/semantics/profile/updated_at`。
4. 断点续跑：同 `--job` 跳过已完成 stage；`--force` 才重算。
5. 重试 ≤2 次、指数退避；失败写 `failed`，不吞异常。
6. 确定性：同素材两次运行 typology/profile 一致；seed 与 workflow hash 入库。
7. 内存守卫：进 C/D 前 Ollama `keep_alive=0` + ComfyUI `/free`；可用内存 > 模型体积 + 12GB。
8. 长任务后台化：>30s 用 nohup，单命令 ≤600s。

## 11. 已知限制与风险（实测/文档确认）

1. **A 轨未生产化**：`orchestrator` D 阶段仍走 LTXV 2B；LTX-2.3 权重就位但**未接代码**；A 轨「无实拍输入」编排未在代码验证。
2. **studio Ollama 仅 `127.0.0.1:11434`**：NAS 部署态无法访问 → polish 会 503。需改 `OLLAMA_HOST=0.0.0.0`（重启服务，需用户拍板）或加反代（#117）。
3. **Brief 未进生成器**：`POST /jobs` 转发 payload 仅 `{input,id,job}`，`brief_id` 只存 web 侧 meta（#98 已记录）。
4. **交付码率不统一**：同参数下 repro 149.7 Mbps/185MB vs new7301 10.0 Mbps（15×），缺上限策略（#116）。
5. **new7301 upscale 偏软**：seg1 lapvar −36.8%、net_gain 0.46–0.60；α/降噪无解，需模型级方案（#114）。
6. **`denoise_report.profile.verified` 易误读**：内置参考值曾被当作实测（#115 修复中）。
7. **报告字段缺口**：旧 job 无 `seed/workflow_sha256/内存`；memory 峰值不可回溯（#118 修复中，只能显式 `not_recorded`）。
8. **D9(a) 前后快照不可回溯**：#4 该项只能记「未验证」。
9. **PG 为预留**：当前 web 仍 files 数据源；`acceptance.*` 表已建未启用。
10. **视频仓库工作区有历史脏文件**（36 项未跟踪/删除，与近期单无关），提交时只 add 本单文件。
11. **Gitea 凭据**曾在子 agent 会话日志中短暂回显（未外发/未落盘），建议轮换一次。
12. **LTX-2.3 许可**：community license，商用条款未逐条核。
13. **ffmpeg 不在 PATH / 无 ffprobe**：脚本必须用绝对路径；时长/流信息用自研 probe 或 `ffmpeg -i`。
